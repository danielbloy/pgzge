# Games

These games serve as examples of how to use the framework. Games under the
`pgzero` directory are designed to only work on Desktop computers running
full Pygame Zero. Games under `multi-platform` are designed to run on all
supported devices that meet the specs of a Adafruit EdgeBadge (which the
games were developer to run on). None of the games are original ideas but
developed as tributes to the legendary games I loved playing as a child.

## Multi Platform

All the games in this section are implementations of the games in my
[Code Club Adventures MakeCode Arcade modules](https://codeclubadventures.co.uk/progressing/#module-1-arcade).
All the games are relatively simple and implemented to ensure this framework
provides equivalent functionality to MakeCode Arcade and a relatively simple
route to transfer across. The Python code is not intended to mimic MakeCode
Arcade, just provide an equivalent set of functionality.
